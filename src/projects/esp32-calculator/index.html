This project is my first real "personal project" that I dedicated time towards. It takes an ESP32 an turns into a calculator that accepts input through a keypad, and displays the results on an OLED Display.

This project serves two goals:
- To improve my ability with designing systems
- To improve my knowledge in C.

As time goes on, I plan to come back to this repository to improve the calculator's capabilites, and to improve the underlying code that the ESP32 runs. All comments are left in the code as a reference towards how the design was handled at the time, and all versions will be seperated in the repository so the progression between them is easily viewable.
